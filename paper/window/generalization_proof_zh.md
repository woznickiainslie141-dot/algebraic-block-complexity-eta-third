# 从 √2 二进制推广到任意实代数无理数与任意整数进制

日期：2026-09-19。对应当前 [英文稿](half_exponent.tex) / [PDF](half_exponent.pdf)。

## 结论

本轮补齐一般半稳定性后，新稿的适用对象可保持为：任意实代数无理数 ξ、任意固定整数 b≥2。得到

\[
\limsup_{L\to\infty}
\frac{p_{\xi,b}(L)(\log\log L)^\gamma}{L(\log L)^{1/2}}=+\infty
\qquad(\gamma>1),
\]

从而得到每个 η<1/2 的 limsup 下界。上一轮范围收窄是半稳定性只核验到特例，并非一般情形存在已知障碍。本轮将这个缺项补入正文，而不只是修改主定理中的对象名称。

这是研究证明稿中的结论，仍需独立数学审稿；本轮没有完成首创性调查。无损失的 η=1/2、γ=1、对所有充分大长度的同阶下界，均不包含在结论中。

## 1. 复位为何也能使用：每个共轭的质量为 1/d

先将 ξ 换成小数部分，令 d=[Q(ξ):Q]≥2。取包含 ξ 的有限 Galois 扩张 K⊂C，设 G=Gal(K/Q)，ι 为复共轭，H=〈ι〉。无穷位对应左陪集 Hσ，归一化权重为

\[
d_v=\frac{|H|}{|G|}.
\]

在位 v 使用 β_v=σ_v^{-1}(ξ) 对应的形式

\[
L_{\beta_v}=-\beta_v X_1+\beta_v X_2+X_3.
\]

因为 ξ 是实数，(ισ)^{-1}(ξ)=σ^{-1}(ξ)，所以这个共轭值不依赖陪集代表。在有理向量 x 上有

\[
\|L_{\beta_v}(x)\|_v=|L_\xi(x)|^{d_v}.
\]

这里沿用原稿及 [BE08 第 5 节](https://arxiv.org/pdf/0709.1560) 的逆共轭运输；没有要求所有共轭在参考复绝对值下都小。

对每个不同共轭 β，满足 σ^{-1}(ξ)=β 的 σ 恰有 |G|/d 个，而且这些 σ 组成完整的 H 左陪集。因此

\[
\boxed{\sum_{v:\,\beta_v=\beta}d_v=1/d.}
\]

这就是当前正文 Lemma 3.1。它同时处理全实分裂域及有复位的分裂域。半稳定性的无穷位贡献可以按 d 个不同共轭分别赋予 1/d 权重来计算；真实的高度仍保留所有原始位和各自绝对值。

## 2. 任意整数进制为何不损失指数

对 p|b 定义

\[
\omega_p=\frac{\operatorname{ord}_p(b)\log p}{\log b},
\qquad\kappa_v=d_v\omega_p\quad(v|p).
\]

则 Σ_{p|b}ω_p=1，Σ_{v|b}κ_v=1。原始权重为

\[
e_v=\begin{cases}
d_v(1,\rho,-\varepsilon),&v|\infty,\\
\kappa_v(-1,-\rho,0),&v|b,\\
0,&\text{其他位}.
\end{cases}
\]

所有有限位仍使用坐标形式，所以计算任意子空间的总有限权重时，恰好合并为一次 (-1,−ρ,0) 的最小权重计算。素数的分裂和分歧已包含于 d_v 中。

局部逼近不等式使用外部参数 Ψ=b^t，直接给出 ‖b^t‖_v=Ψ^(−κ_v)、‖b^r‖_v=Ψ^(−κ_vρ) 和 ‖a‖_v≤1。不需要把 (b^t,b^r,a) 假定为原始整点，因而合数底的公因子不是缺口。

## 3. 一般半稳定性的完整计算

令 0<ε≤1/2、0≤ρ≤1−ε，L_β=−βX₁+βX₂+X₃。

对直线 U，若没有 L_β 消失，则 w_e(U)≤−ε。若两个不同 L_β 消失，则 U=〈(1,1,0)〉，所有 L_β 都消失，权重为 ρ−1≤−ε。否则只有一个共轭形式消失，它只占 1/d≤1/2 的无穷位权重：

- X₁|_U≠0 时，w_e(U)≤−(1−1/d)(1+ε)。
- X₁|_U=0 时，w_e(U)=−(1−1/d)(ρ+ε)。

所以对所有直线都有 w_e(U)≤−ε/2。

对平面 U=ker M，设 A_β=span(L_β,X₂)、B=span(X₁,X₂)。因为不同共轭互异且非零，

\[
A_\beta\cap A_{\beta'}=A_\beta\cap B=\langle X_2\rangle\quad(\beta\ne\beta').
\]

全部分层为：

| M 的位置 | 原始全局权重 |
| --- | --- |
| 不在任何 A_β 或 B 中 | −1−ε |
| 在某个 A_β 中，但不与 L_β 或 X₂ 成比例 | −1−ε+(1−ρ)/d |
| 与某个 L_β 成比例 | −(1−1/d)(1+ε) |
| 在 B 中，但不与 X₁ 或 X₂ 成比例 | ρ−1−ε |
| 与 X₁ 或 X₂ 成比例 | −ε |

每行都不超过 −ε。此处的维数始终是 3，代数次数 d 的增大只改变共轭数量。

中心化后，维数 q 的子空间权重为

\[
w_c(U)=\frac{w_e(U)+q\varepsilon/3}{1+\varepsilon/3}.
\]

故仍得到与二次特例相同的负上界：直线为 −ε/[6(1+ε/3)]，平面为 −ε/[3(1+ε/3)]。这对所有代数子空间成立，并非只核验有理子空间或有限代表。

## 4. 后续计数为什么保持不变

对固定 ξ 和 b，固定其 Galois 扩张及 S={无穷位与 b 的素因子上方的位}，选一个 p₀∤b 上方的有限位作辅助位。这些数据都不随抽取序列长度 J 变化。

现有的变动权重定理本来就允许任意固定有限 S。于是仍有

\[
\#\{j:Q_j\ge C_*(\delta)\}
\ll_{\xi,b}\delta^{-2}\log(2/\delta),
\qquad
\log\log C_*(\delta)
\ll_{\xi,b}\delta^{-2}\log(2/\delta).
\]

常数允许依赖代数数及进制，δ 的幂次保持为 2。原重复词构造用任意有限数字字母表都成立，Q_j=b^{(1+ε/3)t_j} 仍满足 Q_{j+1}>Q_j²。最终代入完全保留 η<1/2 和 γ>1 的范围。
